# Proposal

## Why

Інстанси розгортають навчальні заклади й доповідачі з різною аудиторією, а слухачі часто не україномовні. Інтерфейс має бути доступний мовами `uk` та `en`, причому мову слухачів обирає автор презентації. Це пункт P1 дорожньої карти MVP: «i18n uk/en».

## What Changes

- Підтримка мов `uk` та `en` для всього UI (головна, редактор, екран доповідача, екран слухача, `/admin`, `/health`) через next-intl (або аналог).
- Поле `locale` презентації (`uk|en|auto`) — мова інтерфейсу слухачів; налаштовується в редакторі («мова інтерфейсу слухачів»).
- `auto`: мова визначається з налаштувань браузера слухача; якщо вона не `uk` і не `en` — використовується `DEFAULT_LOCALE`.
- `DEFAULT_LOCALE` (опційна env-змінна, дефолт `uk`, описана в `openspec/specs/runtime-config/spec.md`) — мова за замовчуванням інстансу.
- Словники ніків «прикметник + тварина» для обох мов, як-от «Смілива Сова» або «Brave Owl»; вручну перевірені й без образливих слів.
- Переклади плагінів: `i18n: Record<Locale, Record<string, string>>` у контракті `SlidePlugin`, файли `plugins/<id>/i18n/{uk,en}.json`; повні `en`-переклади для всіх наявних плагінів.

## Поза обсягом

- Інші мови, крім `uk` та `en` (додаються пізніше через PR зі словниками).
- Переклад вмісту слайдів, який вводить автор (питання, варіанти, тексти) — він показується як є.
- Перемикач мови самим слухачем.
- Локалізовані словники фільтра нецензурної лексики (`openspec/changes/add-wordcloud-and-moderation`).

## Capabilities

### New Capabilities
- `localization`: мови інтерфейсу `uk`/`en`, `DEFAULT_LOCALE` як мова за замовчуванням, `locale` презентації для слухачів (`uk|en|auto`), словники ніків обома мовами, переклади плагінів.

## Impact

- **Код:** підключення next-intl (або аналога), словники `messages/{uk,en}.json`, словники ніків `src/lib/nicknames/{uk,en}`, `plugins/<id>/i18n/{uk,en}.json`, налаштування мови в редакторі.
- **БД:** поле `presentations.locale` (`uk|en|auto`) уже є з `openspec/changes/archive/2026-10-20-add-presentation-access/design.md`; ця зміна задає його валідацію й використання.
- **Залежності:** `next-intl` (або аналог).
- **Залежності від інших змін:** `add-slide-plugin-system` (поле `i18n` контракту), `add-live-sessions` (генерація ніків), `add-presentation-editor` (налаштування презентації).
