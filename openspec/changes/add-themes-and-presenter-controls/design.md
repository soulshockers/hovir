# Design

## Context

Поле `theme` (jsonb) у таблиці `presentations` створює `openspec/changes/add-presentation-access` з дефолтом. Мотивацію див. `proposal.md` (Why).

## Decisions

### Модель теми
`presentations.theme jsonb -- { preset: 'light'|'dark'|'bright', accent, logoUrl }`. zod-схема: `preset` — enum, `accent` — hex-колір (`#RRGGBB`), `logoUrl` — URL у Storage або `null`. Дефолт — `light` з акцентом пресета і без логотипа.

### Застосування
Тема перетворюється на CSS-змінні (`--bg`, `--fg`, `--accent`, `--on-accent`) на кореневому елементі екрана доповідача, превʼю і екрана слухача. Плагіни використовують лише ці змінні, а не власні кольори. `--on-accent` обчислюється з відносної яскравості акценту (чорний або білий текст, що дає більший контраст), тож будь-який акцент дає AA. Пресети перевіряються unit-тестом на контраст ≥ 4.5:1.

### Клавіатура
Один обробник `keydown` на екрані доповідача: `F` — Fullscreen API; `←/→`, `PageUp/PageDown` — дії навігації сесії (через HTTP API з `add-live-sessions`); `M` — mute (стан з `add-presentation-effects`, зберігається в `localStorage`); `Q` — видимість компактного QR. Ігнорується, коли фокус у полі вводу. Клікери зазвичай емулюють `PageUp/PageDown` або стрілки, тому окремої підтримки не потрібно.

### Компактний QR
QR генерується на клієнті бібліотекою генерації QR (без запиту до сервера). Видимість («сховати») — локальний стан екрана доповідача, збережений у `localStorage`.

## Risks / Trade-offs

- [Fullscreen API блокується без жесту користувача] → вмикаємо лише з обробника клавіші/кнопки.
- [Логотип з низьким контрастом на темі] → відповідальність автора; превʼю показує результат одразу.
