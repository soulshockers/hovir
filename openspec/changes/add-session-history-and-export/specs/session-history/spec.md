# Spec Delta

## Purpose

Дає автору презентації переглянути історію проведених сесій і результати по слайдах з edit-посилання, без акаунтів.

## ADDED Requirements

### Requirement: Вкладка «Сесії»
Редактор `/e/<editToken>` SHALL мати вкладку «Сесії» з історією проведених сесій цієї презентації: дата й час старту та завершення, код сесії, статус (`lobby` | `live` | `ended`), кількість учасників. Найновіші йдуть першими. Доступ MUST давати лише чинне edit-посилання.

#### Scenario: Перегляд історії
- **WHEN** редактор відкриває вкладку «Сесії» презентації, яку проводили тричі
- **THEN** він бачить три сесії з датами, кодами, статусами й кількістю учасників, найновішу першою

#### Scenario: Present-посилання
- **WHEN** запит до історії сесій надходить з present-токеном
- **THEN** система повертає 404

### Requirement: Результати по слайдах
Для обраної сесії вкладка «Сесії» SHALL показувати результати по кожному слайду зі знімка сесії (`slides_snapshot`): підсумок плагіна (наприклад, розподіл голосів опитування чи рейтинг «Биків») і очки учасників для ігрових слайдів, а також підсумковий лідерборд сесії.

#### Scenario: Результати опитування
- **WHEN** редактор відкриває завершену сесію з опитуванням
- **THEN** він бачить розподіл голосів цього опитування в сесії

#### Scenario: Слайд змінено після сесії
- **WHEN** після сесії автор змінив або видалив слайд
- **THEN** результати сесії показуються за знімком слайдів на момент старту

### Requirement: Без персональних даних
Історія сесій SHALL містити лише анонімні ніки учасників і їхні результати. IP-адреси та інші персональні дані MUST NOT зберігатися в БД.

#### Scenario: Вміст історії
- **WHEN** редактор переглядає учасників сесії
- **THEN** він бачить лише автогенеровані ніки й очки
