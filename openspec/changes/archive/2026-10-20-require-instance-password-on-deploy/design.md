# Design

## Context

Мотивацію див. у `proposal.md` (Why). Зараз кнопка в README має лише `repository-url`, `project-name`, `repository-name` і `stores` (інтеграція Supabase). Під час роботи `INSTANCE_PASSWORD` опційна (`openspec/specs/runtime-config/spec.md`), і від неї залежать захист створення, попередження про відкритий інстанс і `/admin` (`openspec/specs/instance-admin/spec.md`).

## Goals / Non-Goals

**Goals:** новий інстанс, розгорнутий кнопкою, одразу захищений паролем, а власник бачить у майстрі Vercel, навіщо пароль і де про нього прочитати.

**Non-Goals:** перевірка довжини чи складності пароля в застосунку; примусова наявність пароля під час роботи (відкритий інстанс лишається можливим); зміни для інстансів, розгорнутих раніше.

## Decisions

### Параметри Vercel Clone URL

- `env=INSTANCE_PASSWORD`: Vercel показує поле й не починає деплой без значення. Змінні, які ставить інтеграція Supabase, у `env` не додаємо: їх заповнює `stores`.
- `envDescription`: одне речення українською, URL-кодоване.
- `envLink=https://github.com/soulshockers/hovir#instance_password`: абсолютне посилання, бо майстер Vercel відкривається поза GitHub. Якір дає заголовок `## INSTANCE_PASSWORD` (GitHub прибирає регістр і лишає `_`). ASCII-якір обрано, щоб не залежати від відсоткового кодування кириличних заголовків.
- `envDefaults` не використовуємо: Vercel забороняє дефолти для секретів, а спільний пароль з README був би відомий усім.

Альтернатива — мати дві кнопки («захищений» і «відкритий» інстанс). Відхилено: рішення власника продукту — одна кнопка з обов'язковим паролем, а відкритий режим лишається через видалення змінної.

### Рекомендація 12 символів не перевіряється

Перевірка в zod-схемі env робила б конфігурацію наявних інстансів із коротшим паролем невалідною (усі API → 503). Тому це лише текст в описі майстра й README.

## Risks / Trade-offs

- [Власник забув пароль] → його можна змінити у Vercel → Settings → Environment Variables і зробити Redeploy; це завершує сесії `/admin`, а презентації й посилання лишаються. README описує це в розділі `INSTANCE_PASSWORD`.
- [Перейменування заголовка README ламає `envLink`] → розділ має стабільний ASCII-заголовок `## INSTANCE_PASSWORD`. Задача на перевірку якоря — у `tasks.md`.
