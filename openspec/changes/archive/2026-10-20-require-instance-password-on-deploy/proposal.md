# Proposal

## Why

Зараз кнопка «Deploy to Vercel» розгортає відкритий інстанс: `INSTANCE_PASSWORD` не запитується, тож будь-хто з адресою може створювати презентації, а майстер-доступу `/admin` (відновлення втрачених посилань) немає. Власник дізнається про це лише з попередження на головній. Рішення власника продукту: деплой кнопкою має вимагати пароль, щоб новий інстанс за замовчуванням був захищеним.

## What Changes

- URL кнопки «Deploy to Vercel» у README отримує параметри Vercel Clone URL:
  - `env=INSTANCE_PASSWORD` — майстер Vercel вимагає ввести значення перед деплоєм;
  - `envDescription` — коротке пояснення українською: пароль на створення презентацій і майстер-доступ `/admin`, щонайменше 12 символів, збережіть його;
  - `envLink` — абсолютне посилання на розділ README про `INSTANCE_PASSWORD` (`https://github.com/soulshockers/hovir#instance_password`).

  `envDefaults` не використовується: Vercel забороняє дефолти для секретів, а спільний дефолтний пароль знецінив би захист.
- README: новий розділ `INSTANCE_PASSWORD` (на нього веде `envLink`), оновлені кроки деплою (майстер попросить пароль), у таблиці env `INSTANCE_PASSWORD` позначено «обов'язкова при деплої кнопкою». `.env.example` уточнює те саме.
- Під час роботи застосунку `INSTANCE_PASSWORD` лишається опційною: якщо власник пізніше видалить змінну, інстанс стає відкритим, а головна показує попередження (поведінку `instance-admin` не змінено).
- Довжину пароля (≥ 12 символів) застосунок не перевіряє: це рекомендація в описі майстра й README. Примусова перевірка зробила б невалідною конфігурацію наявних інстансів із коротшим паролем.

### Modified Capabilities

- `instance-deployment`: деплой кнопкою вимагає ввести `INSTANCE_PASSWORD`. README документує змінну як обов'язкову при деплої кнопкою, а решту опційних змінних — з дефолтами.
- `runtime-config`: нова вимога «INSTANCE_PASSWORD опційна під час роботи» (довжина не перевіряється); файл-приклад позначає змінну як «обов'язкова при деплої кнопкою».

`presentation-access` і `instance-admin` не змінюються: їхні вимоги вже залежать лише від того, чи задано пароль під час роботи, а попередження про відкритий інстанс лишається.

## Impact

- **Документація:** `README.md` (URL кнопки, кроки деплою, таблиця env, новий розділ `INSTANCE_PASSWORD`), `.env.example` (коментар).
- **Код, API, БД:** без змін; нових залежностей і env-змінних немає.
- **Наявні інстанси:** не зачеплені. Змінюється лише майстер Vercel для нових деплоїв кнопкою.
