# Spec Delta

## Purpose

Статичний слайд (`static`) — звичайний контент презентації: заголовок, текст у Markdown і зображення в одному з трьох розміщень; слухачі в цей час дивляться на екран.

## ADDED Requirements

### Requirement: Поля статичного слайда
Конфіг слайда `static` SHALL містити поля: заголовок, текст (Markdown), зображення (файл у Supabase Storage, опційно), розміщення (layout): заголовок / текст+картинка / картинка на весь екран.

#### Scenario: Налаштування в редакторі
- **WHEN** автор додає слайд `static`
- **THEN** форма містить поля заголовка, тексту в Markdown, зображення та вибору розміщення з трьох варіантів

### Requirement: Розміщення контенту
Екран доповідача SHALL рендерити слайд відповідно до layout: «заголовок» — лише заголовок по центру; «текст+картинка» — заголовок, текст і зображення поруч; «картинка на весь екран» — зображення на весь кадр слайда.

#### Scenario: Картинка на весь екран
- **WHEN** доповідач показує слайд з layout «картинка на весь екран»
- **THEN** зображення займає весь кадр слайда

#### Scenario: Текст і картинка
- **WHEN** layout — «текст+картинка»
- **THEN** на екрані видно заголовок, відрендерений Markdown-текст і зображення

### Requirement: Слухач дивиться на екран
Слайд `static` SHALL бути неінтерактивним (`interactive: false`): слухач бачить екран «Дивіться на екран» (зі своїм ніком і поточними очками). Слайд MUST NOT нараховувати очки.

#### Scenario: Екран слухача
- **WHEN** доповідач перемикає на статичний слайд
- **THEN** слухачі бачать «Дивіться на екран»

### Requirement: Markdown без сирого HTML
Текст слайда SHALL рендеритися як Markdown без сирого HTML: HTML-теги у тексті MUST NOT виконуватися чи вставлятися в DOM, а показуються як текст або відкидаються. Посилання з небезпечними схемами (`javascript:`) MUST відкидатися.

#### Scenario: Спроба вставити скрипт
- **WHEN** автор пише в тексті `<script>alert(1)</script>` або `<img src=x onerror=...>`
- **THEN** на екрані немає виконаного HTML і скрипт не запускається

#### Scenario: Звичайне форматування
- **WHEN** текст містить `**жирний**`, списки й посилання `https://…`
- **THEN** вони рендеряться як Markdown-форматування
