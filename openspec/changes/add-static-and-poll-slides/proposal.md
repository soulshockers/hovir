# Proposal

## Why

Після контракту плагінів, редактора й live-сесій потрібні базові типи слайдів, з яких складається будь-яка презентація: звичайний контент і опитування. Це пункт P0 дорожньої карти MVP: «Плагіни: `static`, `poll`, **`bulls-and-cows`**» (гра — окрема зміна `add-bulls-and-cows`). Вони ж — найпростіші приклади контракту для авторів нових плагінів.

## What Changes

- Плагін `static` (статичний контент, `interactive: false`, `scoring: false`, категорія `content`):
  - поля: заголовок, текст (Markdown), зображення (Supabase Storage), розміщення (layout: заголовок / текст+картинка / картинка на весь екран);
  - слухач бачить екран «Дивіться на екран»;
  - Markdown рендериться без сирого HTML.
- Плагін `poll` (опитування, `interactive: true`, `scoring: false`, категорія `poll`):
  - поля: питання, 2–8 варіантів, режим `single` | `multiple`, чи показувати результати слухачам після голосування, чи приховувати результати на екрані до натискання «Показати»;
  - екран доповідача: live-діаграма (стовпчики) з кількістю голосів і відсотками;
  - слухач голосує один раз; зміну голосу до закриття раунду можна дозволити опцією;
  - очок не дає.
- Unit-тести логіки обох плагінів і проходження тест-хелпера безпеки.

## Поза обсягом

- Інші типи слайдів (`quiz`, `wordcloud`, `scale`, `qna`, `bulls-and-cows`, `leaderboard`) — окремі зміни.
- Застосування тем до слайдів (`add-themes-and-presenter-controls`), анімації появи стовпчиків (`add-presentation-effects`).
- Експорт результатів опитування в CSV (`exportRows`, `add-session-history-and-export`).
- CSP-заголовки інстансу (`add-quality-gates`).
- Квіз з кількома правильними відповідями, ранжування, відкриті відповіді (подальші етапи).

## Capabilities

### New Capabilities
- `static-slide`: слайд зі статичним контентом (заголовок, Markdown, зображення, розміщення) і екран «Дивіться на екран» для слухачів.
- `poll-slide`: опитування з одним чи кількома варіантами, правила голосування, live-діаграма й керування показом результатів.

## Impact

- **Код:** `plugins/static/`, `plugins/poll/` (маніфест, схема, сервер, `Presenter.tsx`, `Audience.tsx`, `Preview.tsx`, `i18n/{uk,en}.json`, `server.test.ts`), реєстрація в `plugins/index.ts`.
- **Залежності від інших змін:** `add-slide-plugin-system`, `add-presentation-editor` (форма, `slide-media`), `add-live-sessions` (сесії, раунди, actions/state API, канал).
- **Залежності:** рендерер Markdown без сирого HTML (наприклад, `react-markdown` без `rehype-raw`).
- **БД / API:** без нових таблиць; голоси зберігаються в стані слайда сесії.
